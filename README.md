# AION2 데바니온 최적화

직업과 보유 포인트에 맞춰, 필수 노드를 모두 연결하고 일반 노드를 원하는 우선순위로 확보하는 도구입니다. 2026.11.11 패치 데이터를 기준으로 계산합니다.

저장소: [kaizero-dev/aion2-daevanion-optimizer](https://github.com/kaizero-dev/aion2-daevanion-optimizer)

## 사용법

1. **직업과 총 가용 포인트**를 입력합니다. 포인트는 5개 보드 전체가 함께 사용합니다.
2. **필수 노드 지정**에서 유일·전승·희귀 탭의 필요한 항목을 선택합니다. 같은 이름의 노드가 여러 보드나 여러 위치에 있으면 모두 필수로 지정됩니다. 항목에 마우스를 올리거나 키보드로 포커스하면 해당 보드명을 볼 수 있습니다.
3. **일반 노드 우선순위**를 드래그하거나 위·아래 버튼으로 조정합니다. 위에 있는 항목을 먼저 최대한 확보합니다.
4. **최적화 계산**을 누릅니다. 계산 중에는 **중단**할 수 있으며 입력 설정은 유지됩니다.
5. 보드 탭을 바꾸며 활성 노드를 확인합니다. 노드에 마우스를 올리거나 포커스하면 이름과 효과가 표시됩니다. 아래 결과 요약에는 **5개 보드 전체의 적용 효과와 일반 노드별 활성 개수/전체 개수**가 표시됩니다.

처음 열거나 새로고침하면 검성·837포인트·특수 노드 전부 필수로 시작합니다. 기본 일반 우선순위는 공격력 → 치명타 → 방어력 → 최대 생명력 → 최대 정신력 → 치명타 저항입니다. 자동 계산은 하지 않으며, 설정과 결과는 브라우저에 저장되지 않습니다.

직업을 바꾸면 새 직업의 특수 노드를 모두 선택하고 일반 우선순위를 기본값으로 되돌립니다. 입력한 포인트는 유지합니다. 직업·포인트·필수 선택·우선순위를 바꾸면 이전 결과가 초기화되므로 다시 계산하세요. 보드·등급 탭만 바꾸면 결과는 유지됩니다. 포인트 입력이 비어 있으면 계산할 때 0으로 처리합니다.

## 최적화 전략

필수 노드를 모두 활성화하고 각 보드의 시작점에서 상하좌우로 연결되는 조합만 계산합니다. 시작점은 무료이며, 일반 1P·희귀 2P·전승 3P·유일 4P를 사용합니다. 연결에 필요한 노드의 비용도 예산에 포함됩니다. 빈칸이나 대각선을 통과하거나 다른 보드를 경유할 수 없습니다.

1. 1순위 일반 노드의 활성 개수를 최대화합니다.
2. 1순위 최대 개수를 유지하면서 2순위를 최대화하고, 같은 방식으로 6순위까지 계산합니다.
3. 여섯 순위의 개수가 모두 같으면 사용 포인트가 가장 적은 결과를 선택합니다.
4. 비용도 같으면 필수 이외의 특수 노드가 적은 조합, 그다음에는 노드 식별자 순서로 결과를 결정합니다.

예를 들어 1순위의 최대 개수가 35개라면, 35개를 유지하는 범위에서 2순위를 늘립니다. 이때 선택 위치와 연결 경로는 바뀔 수 있습니다. 1순위를 전부 확보하지 못해도 나머지 순위까지 계산하며, 2순위를 늘리기 위해 1순위를 34개로 줄이지 않습니다.

우선순위는 일반 노드의 **개수**를 기준으로 합니다. 총 활성 개수나 전투력을 최대화하는 목표와는 다르며, 모든 포인트를 소진할 필요도 없습니다. 연결용 일반 노드도 개수와 적용 효과에 포함됩니다.

## 계산할 수 없는 경우

- **데바니온 포인트가 부족합니다.**: 필수 노드와 연결을 모두 확보할 예산이 부족합니다. 포인트나 필수 선택을 조정해 다시 계산하세요.
- **불가능한 노드 설정입니다.**: 시작점에서 도달할 수 없는 필수 노드가 있습니다.
- **최적화가 어렵습니다. 개발자에게 문의하세요.**: 계산을 완료하지 못했습니다. 경고 확인 후 다운로드되는 설정 JSON을 개발자에게 전달하면 당시 입력을 확인할 수 있습니다. 파일은 자동 업로드되지 않습니다.

계산은 사용자의 브라우저에서 실행합니다.
