# AION2 데바니온 최적화

직업과 보유 포인트에 맞춰 필수 노드를 연결하고, 일반 노드를 우선순위대로 최대한 확보합니다. (2026.11.11 패치 기준)

## 사용법

1. 직업과 총 가용 포인트를 입력합니다.
2. 필수 노드를 선택하고 일반 노드 우선순위를 조정합니다.
3. **최적화 계산**을 누르고 보드별 결과와 적용 효과를 확인합니다.

## 최적화 전략
필수 노드를 먼저 확보합니다.
이후 상위 순위 노드의 최대 개수를 유지하며 다음 순위의 개수를 최대화합니다.
개수가 같으면 사용 포인트를 최소화합니다.

## 라이센스
출처 표기 없이 수정 및 재배포 가능
